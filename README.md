# Лабораторная работа №1. Алгоритмы маршрутизации

**Дисциплина:** Программное обеспечение компьютерных сетей  
**Вариант:** 4  
**Тема:** Программное обеспечение сетевого уровня (модель OSI). Алгоритмы маршрутизации

## Реализованные алгоритмы

- **Алгоритм Беллмана-Форда** — временная сложность O(n · m), обнаружение отрицательных циклов.
- **Алгоритм Дейкстры** с бинарной пирамидой (heapq) — временная сложность O((n + m) · log n).

## Файлы проекта

| Файл | Назначение |
|---|---|
| `graph.py` | структура взвешенного ориентированного графа и генератор случайных графов |
| `bellman_ford.py` | реализация алгоритма Беллмана-Форда + восстановление пути |
| `dijkstra.py` | реализация алгоритма Дейкстры |
| `main.py` | консольный интерфейс для запуска обоих алгоритмов |
| `benchmark.py` | замер производительности на графах от 100 до 2000 вершин |

## Запуск

### Требования

- Python 3.10 или выше
- Стандартная библиотека (без внешних зависимостей)

### Запуск основного приложения

    python main.py

Программа запросит:

- число вершин `n` (для теста — 500);
- плотность рёбер `density` (для теста — 0.05);
- вершину-источник `src` (0);
- вершину-получатель `dst` (499).

### Запуск бенчмарка

    python benchmark.py

Будет выведена таблица сравнения времени работы двух алгоритмов.

## Результаты

При `n = 500`, `density = 0.05`, `src = 0`, `dst = 499`:

- кратчайшее расстояние — **28**;
- путь — **[0, 7, 232, 22, 499]**;
- время Беллмана-Форда — **7.212 мс**;
- время Дейкстры — **1.063 мс**;
- ускорение — **6.8×**.
